⚡ bitsy SMS Bitsy game editor → Sega Master System ROM generator
~ about bitsy SMS ~
Make tiny games in the Bitsy editor, then export them as real Sega Master System ROMs (.sms files) you can load in any SMS emulator.

How to edit: Draw 8×8 tiles and sprites in the paint panel, place them on the 16×16 room map, pick 3 colors, write dialog for sprites.
How to export: Use the three SMS Export steps below — Generate → Compile → Assemble.

SMS limits: up to ~20 tiles · ~8 NPCs · ~8 rooms · dialog ≤ 38 chars per NPC · colors mapped to SMS 2-bit/channel palette (64 colors total).

Requirement: The compiler step loads CVBasic-emscripten from GitHub Pages via hidden iframes. Serve this folder over HTTP — e.g. python3 -m http.server — then open http://localhost:8000/.

1 Generate CVBasic source

Converts your Bitsy world into a CVBasic .bas program targeting the Sega Master System (Z80 / Mode 4).

2 Compile to Z80 assembly

Runs CVBasic-emscripten in a hidden iframe (Emscripten/WASM) to produce Z80 .asm output.

Requires internet + HTTP server.
python3 -m http.server then http://localhost:8000/

3 Assemble to SMS ROM

Runs gasm80 to produce a binary, adds the SEGA ROM header, and downloads the .sms file.

Load the .sms in Emulicious, MEKA, Fusion,
or any Sega Master System emulator.
